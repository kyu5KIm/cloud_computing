# Cloud Notes — 클라우드 서술형 학습실

DataCamp 기반 7개 강의·21개 챕터를 정리하고 종이 오픈북 서술형 시험을 준비하는 개인 로컬 웹앱입니다. DataCamp 공식 제품·원문 문제·기출 제공 서비스가 아닙니다.

## 클론하고 실행하기

Node.js **22 이상**과 Git이 필요합니다. 별도 npm 패키지 설치 없이 실행합니다.

```powershell
git clone https://github.com/kyu5KIm/cloud_computing.git
cd cloud_computing
npm start
```

[학습실](http://127.0.0.1:4173/) 또는 [서술형 시험](http://127.0.0.1:4173/#exams)을 엽니다. Windows에서는 start-study.cmd로도 실행할 수 있습니다. 종료는 터미널에서 Ctrl+C입니다. 포트가 사용 중이면 CLOUD_STUDY_PORT로 다른 포트를 지정하세요.

기능 PR이 아직 main에 병합되지 않았다면 클론 후 `git switch codex/cloud-study-midterm`을 실행하고 `npm start`로 시작하세요. main에는 최초 프로젝트 설정만 있으며 PR 병합 후에는 위 기본 명령만으로 실행됩니다.

다른 사람이 클론해도 학습·시험 작성 기능을 사용할 수 있습니다. 진도·메모·답안은 각자의 .runtime/에 저장됩니다. 계정 인증과 개인 답안은 공유하지 않습니다. **단일 사용자·동일 컴퓨터 사용 전제**이며 서버는 127.0.0.1에만 열립니다. LAN·터널·공개 웹 서비스로 노출하지 마세요.

## 구현한 기능

- 7개 강의·21개 챕터 탐색·검색·개인 진도와 메모 저장.
- 300개 수업 항목의 직접 확인 상태·짧은 자체 해설·출처 연결. 오류·제출 피드백·실제 실습은 구분합니다.
- 전체 21개 챕터의 학습 목표·선수 개념·필요성·117개 개념 설명·작동 흐름·비교표·가상 사례·오답 보완·용어 총정리.
- 챕터별 서술형 연습 3개씩 총 63개: 자체 작성 모범답안·필수 논점·10점 루브릭·대안 표현·재작성 안내. 기존 입문 답안의 저장 키는 유지합니다.
- 강의별 세 챕터 연결 복습표와 동일한 학습안을 사용하는 화면·선택 인쇄.
- 별도 서술형 시험: 챕터당 1문항, 총 21문항·210점. 확인한 개념·비교·선택·분류·과정을 서술형으로 재구성한 자체 작성 예상문제입니다.
- 전체 작성 후 일괄 제출, 초안 자동 저장, 제출 이력, 중복 제출 방지, 제출 후 모범답안·필수 논점 비교.
- 채점 결과의 문항·버전·점수 범위·출처·답안 인용 검사, 서버 총점 재계산. 평가 보류를 0점으로 확정하지 않습니다.
- JSON 백업, 저장 충돌 보호, 손상 파일 덮어쓰기 차단, 강의·챕터 선택 인쇄 초안.

300개 기록은 모든 실제 콘솔 실습 수행이나 사용자 숙달을 뜻하지 않습니다. [직접 확인 기록](docs/datacamp-full-study-progress.md)에 범위와 미확인 항목이 있습니다. DataCamp 원문을 보려면 각자의 이용 권한이 필요합니다. [21개 챕터 보완 범위와 검증 원칙](docs/chapter-expansion.md)을 확인하세요. 최종 PDF의 페이지 번호 색인과 전체 인쇄 레이아웃 검증은 남아 있습니다.

## Codex 인증·채점 제한

**오른쪽 학습 질문 챗봇은 ChatGPT로 로그인한 Codex CLI를 사용합니다. 자동 채점은 아직 미연결입니다.** 챗봇은 GPT‑6.1 Sol · Light(`gpt-6.1-sol`, `low`)로 고정하고 현재 챕터/전체 수업에서 관련 근거를 선택합니다. 일상 질문은 범위 검사에서 차단하며, 부족한 근거를 현재 사실처럼 답하도록 요청하지 않습니다.

검증된 Windows CLI `0.163.0-alpha.10.2`만 실행합니다. 해당 버전이나 ChatGPT 인증이 없으면 요청을 중단하고 API 키·다른 모델로 전환하지 않습니다. 향후 CLI 업데이트 시 [질문 실행 경계](docs/study-chat.md)를 재검증해야 합니다. 질문 전송에만 계정 사용량이 발생하며 패널 열기·입력·인쇄는 모델을 호출하지 않습니다. 대화는 파일에 저장하지 않고 탭과 서버 메모리에 일시 유지합니다.

시험 전체 제출과 모범답안 비교는 가능하지만 채점 요청은 연결 대기로 보존하고 AI 점수를 만들지 않습니다. Codex 사용자가 클론해도 자동 채점이 바로 활성화되지는 않습니다.

목표 인증은 각자가 공식 Codex CLI에서 자신의 ChatGPT 계정으로 로그인하는 방식입니다. API 키 호출과 자동 API fallback은 구현하지 않습니다. 인증 파일을 저장소·웹페이지에 넣지 마세요.

채점 모델 설정은 gpt-6.1-sol, 추론 강도 low(Light)입니다. 설정·로그인 성공만으로 계정의 모델 접근·실제 응답 성공을 보장하지 않습니다. [공식 모델 안내](https://learn.chatgpt.com/docs/models), [인증 안내](https://learn.chatgpt.com/docs/auth)를 참고하세요.

시험 자동 채점 연결 전 OS 파일 접근·실행 도구·플러그인·전역 설정·네트워크 경계를 검증해야 합니다. 고정 CLI 인수 계약과 결과 검증기는 완성된 실행 연동이 아닙니다. [시험 검증과 남은 연결 작업](docs/exam-validation.md)에 구분했습니다.

학습 질문 또는 향후 실제 채점 요청에서는 질문·최근 대화 또는 답안·문항·채점 기준·근거가 OpenAI로 전달되며 각 계정의 Codex 사용 조건을 따릅니다. 잔여량·정확한 차감·무료·무제한·무과금을 보장하지 않습니다. [공식 사용 조건](https://learn.chatgpt.com/docs/pricing)을 확인하세요.
