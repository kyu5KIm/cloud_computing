# 인쇄용 학습 노트

챕터 인쇄 또는 인쇄용 학습 노트에서 강의를 선택하면 A4 미리보기를 구성한다. 인쇄 / PDF 저장 버튼이 브라우저 인쇄 창을 연다. 미리보기 준비와 인쇄는 Codex를 호출하지 않는다.

- 핵심 개념 → 비교표 → 작동 흐름 → 서술형 문제·답안 → 관련 보강 내용 → 페이지 번호 색인 순서.
- 사용자 요청에 따라 표지·출처 배지·URL·채점표·개인 메모·채팅은 기본 출력에서 제외한다. 화면의 출처와 검증 정보는 유지한다.
- `print-edition.mjs`는 검수한 인쇄본의 교수 PPT 보완 내용을 보관한다. `printGroups`는 복제한 데이터에 적용하여 원본 카탈로그와 학습 상태를 변경하지 않는다. 교수 PDF 원문·녹취나 타 서비스의 정리본은 포함하지 않는다.
- A4, 여백 10mm. 기본 본문 10pt, 한 페이지 구성이 가능한 밀집 내용은 9.8~9.5pt까지 조정한다. 맞지 않으면 다음 페이지로 넘기며 내용을 숨기거나 자르지 않는다.
- 폰트 로딩 후 실제 높이로 페이지를 나눈다. 표는 행 단위로 나누고 머리글을 반복한다. 챕터 첫 페이지 위치로 색인을 생성한다. 페이지 수는 선택 범위와 브라우저 폰트에 따라 달라질 수 있다.
- 현재 Windows 맑은 고딕 환경에서 전체 21챕터는 30페이지, 양면 15장으로 확인했다. 이전 별도 PDF와 보강 내용·색인 배치 순서는 다를 수 있다.
- 인쇄 설정은 실제 크기 100%, A4, 여백 1cm, 양면 긴 쪽 넘김을 사용한다. 브라우저 머리글·바닥글은 끈다. 최종 물리 출력은 사용자가 인쇄 창에서 확정한다.
- 닫기/Escape로 학습 화면에 복귀하며 기존 진도·메모·답안은 보존한다. Ctrl/Cmd+P도 준비 화면을 연다.

검증: 자동 테스트는 전체 선택·부분 선택·원본 불변성·교수 보완·메모 제외·문자 이스케이프를 확인한다. 브라우저에서는 전체/단일 챕터의 페이지 구성, 넘침, 닫기와 복귀를 확인한다.

## 별도 양면 한 장 키워드 목차

- 기존 30페이지 PDF의 쪽 번호를 유지한 독립된 A4 세로 목차다. 본문 PDF 앞에 병합해 번호를 바꾸지 않는다.
- 1~15쪽과 16~30쪽을 두 페이지에 나누어 총 30개 행과 우선 복습 별표 18개를 담는다. 사방 10mm 여백, 주제 굵게 표시, 키워드 별도 줄, 본문 10.5pt 이상으로 구성한다.
- Windows 맑은 고딕 및 Python reportlab, pypdf가 필요하다. 저장소 루트에서 `python scripts/build-keyword-index.py`로 생성한다.
- 기본 출력: `exports/pdf/cloud_keyword_index.pdf`. PDF는 기존 Git 제외 정책을 유지하며 재생성용 내용·스크립트만 커밋한다.
- 2페이지 여부와 페이지별 15개 행 배치, 전체 텍스트·별표 수를 검사한다. 생성 후 PDF를 렌더링해 줄바꿈과 잘림을 확인한다.
