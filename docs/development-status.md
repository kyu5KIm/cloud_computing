## 출처 검증 기록

2026-10-12에 7개 공식 DataCamp 강의 페이지의 Course outline을 직접 열어 확인했습니다. URL과 챕터별 확인 위치는 `content/catalog.mjs`에 있습니다.

사용자가 제공한 7개 app.datacamp.com/learn/courses 링크를 강의 데이터에 등록했습니다. 사용자가 직접 로그인한 뒤 입문 1챕터의 세 이론 영상 대본(소개 ex=1, 클라우드의 힘 ex=4, 서비스 모델 ex=7)을 직접 확인했습니다. 강의 페이지에는 업데이트 2026년 7월이 표시됩니다. 공식 연습문제 ex=2는 초기 오류 이후 다시 로드되어 문제 요구·선택지를 확인했습니다. 답안을 제출하거나 공식 정답·해설을 열람하지 않았습니다. 원문 문항을 복제하지 않고 요구만 짧게 요약했습니다.

공개 PDF·projector 자료는 최초 구현의 참고 출처로 남겼으며, 입문 챕터의 게시 요약은 현재 로그인된 수업 대본 출처로 교체하고 보강했습니다. 전체 원문을 저장·배포하거나 문항을 대량 수집하지 않았습니다.

기술 근거는 [비대화형 호출](https://learn.chatgpt.com/docs/non-interactive-mode), [설정 참조](https://learn.chatgpt.com/docs/config-file/config-reference), [인증](https://learn.chatgpt.com/docs/auth), [요금](https://learn.chatgpt.com/docs/pricing)을 다시 열어 확인했습니다. 설치된 CLI는 0.162.1이며 ChatGPT 로그인 진단이 성공했습니다. 실제 모델 호출은 하지 않았습니다.
