총 21개 학습안, 117개 개념 설명, 작동 과정 21개, 비교표 21개, 자체 작성 가상 사례 21개, 오답 보완 42개, 서술형 연습 63개다. 기존 별도 시험 21문제와 연습을 구분한다. 강의별로 세 챕터를 연결하는 복습표를 제공한다.

각 챕터는 선수 개념 → 목표 → 필요성 → 개념 → 원인·결과가 있는 과정 → 비교 → 요구·선택·작동·제약 사례 → 오개념 수정·짧은 재작성 → 요약·용어 → 서술형 연습으로 구성한다. 연습마다 근거 개념, 예상 분량, 네 필수 논점, 10점 루브릭, 대안 표현, 흔한 오류와 모범답안 버전을 연결했다.

## 근거와 구분

- `study-run.json`의 기존 300개 직접 확인 기록을 재사용했다. 이번 작성일을 원문 재열람일로 바꾸거나 새로 모든 수업을 다시 수행했다고 주장하지 않는다.
- `content/lessons/c01.mjs`~`c07.mjs`에서 설명별 `ex`를 지정하고 `expanded-lessons.mjs`에서 해당 챕터의 확인된 출처와 연결한다. 미확인·로딩 오류·공식 해설만 열어본 미완료 실습은 본문 사실 근거로 채택하지 않는다.
- 개념은 **DataCamp 강의 확인 내용**, 흐름·비교는 **학습용 재구성**, 새 사례는 **학습용 가상 사례**, 문제·모범답안·오답 보완은 **자체 작성**으로 구분한다. 원문 대본·문항·공식 정답의 대량 재배포가 아니다.
- 기존 외부 공식 보충설명은 독립된 절에 표시한다. DataCamp의 부정확·보류 표현을 사실로 승격하지 않는다. 예: RBAC 상속의 단순 제거, CLI와 특정 셸의 동일시, 분산과 확장의 혼동, 예산의 자동 차단 보장.
- 교수 PDF 원본·OCR·그림·교수의 연락처·문항 원문은 저장소에 추가하지 않는다. 새 사례는 자체 작성이며 교수 사례의 실제 기관 성과로 표시하지 않는다.
- 제품 명칭·가격·할인·지원 플랜·서비스 제공 상태는 원문 확인 시점의 학습 맥락이다. 현재 운영 권고나 신규 도입 보장이 필요한 경우 공식 문서를 별도로 확인한다.

## 호환성과 제한

기존 `Q-scale`, `Q-models`, `Q-virtualization` 저장 키를 유지하고 모범답안 버전을 갱신했다. 저장된 답안·메모·진도·제출 이력은 이번 콘텐츠 추가로 다시 쓰지 않는다. 새 질문도 기존 자동 저장·네 항목 자기 점검·내보내기를 사용한다. 자기 점검을 AI 채점 점수로 바꾸지 않는다.

화면과 인쇄는 같은 렌더러의 개념·흐름·비교·사례·오답·요약·용어를 사용한다. 인쇄에는 선택한 챕터의 모범답안·배점·필수 논점과 출처를 추가한다. 300개 진행 기록은 화면에서 펼쳐 볼 수 있다. 종이 노트의 색인은 챕터 ID 기준이며 최종 PDF 페이지 번호 색인은 아직 제공하지 않는다.

실제 Codex 질문·자동 채점은 기존의 미연결 상태를 유지한다. 이번 작업·자동 테스트는 모델 추론을 실행하지 않는다.
