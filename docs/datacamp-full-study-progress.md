## 웹사이트와 한계

확인 기록·출처·짧은 자체 해설을 챕터 화면과 인쇄 초안에 연결한다. 원문 문제·개인 성찰 답안을 대량 복제하지 않는다. 모든 챕터의 서술형 예상문제·루브릭·모범답안과 최종 PDF 색인 검증은 미완료다. 실제 Codex 추론은 보안 격리 검증 전 비활성 상태다. 사용자 진도·개인 답안은 자동 완료로 변경하지 않는다. 이전 외부 문서 보충설명은 DataCamp 내용과 분리해 보존한다.
